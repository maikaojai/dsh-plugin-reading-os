# ReadingOS for DeepSeek Harness

> 让散落在 macOS 苹果图书中的划线与感触，重新在日常思考中鲜活起来。

![ReadingOS 首页看板](assets/01-responsive-dashboard.png)

---

### 为什么做 ReadingOS？

平时在 Mac 自带的「图书（Apple Books）」里翻看电子书，遇到真正触动自己的句子，随手划上一道线。那些句子，不是冰冷的数据，而是自己在某个时刻最真切的体会与感触。

然而在日常阅读中，这些有价值的痕迹往往面临着几种断裂：

- **读完即沉睡**：划线静静沉在 macOS 底层的数据库里，合上书之后便很少再被翻阅，逐渐成为数字灰尘；
- **导出极其折磨**：在官方「图书」里要想把划线提取出来归档，传统方式只能靠繁琐的“通过邮件分享”给自己，再一段段复制粘贴，格式零散，稍微长一点的书就令人望而生畏；
- **与 AI 探讨的阻力**：想就某个观点和 AI 深入聊聊时，需要手动选中、复制、切换窗口、粘贴，摩擦力极高；更常遇到的是，AI 往往一味迎合，反倒加深了认知局限与信息茧房；
- **缺少收尾与沉淀**：一本书读完了，几十上百条划线散落各处。想要做一次高信息密度的系统复盘，或者想把这些真实的触动提炼为创作选题与思考手记，往往缺少一个顺手、整洁的出口。

**ReadingOS 正是为了消弭这些摩擦力而生。**  
它在 DeepSeek Harness 侧边栏为你构筑了一个纯本地运行的个人阅读空间——不只是一面阅读看板，更是一套连接 **「输入（原生划线）➔ 思考（三维辩证研读）➔ 输出（选题孵化与复盘报告）」** 的轻盈闭环。

### 核心体验与设计

#### 1. 自动同步，足迹尽览
直接读取 macOS「图书」App 底层数据库与本地下载书库（`~/Downloads`），365 天阅读热力图、藏书资产分布与原生阅读进度（精准同步苹果图书百分比）完全同步。无需任何手动配置，每一次打开，都是你最新的阅读状态。

#### 2. 三合一即时藏书检索
顶栏保留极简的全局搜索胶囊，按快捷键 `/` 即可随时唤起：
- **空状态即全量书架**：默认以卡片流列出全部已划线藏书（按批注量排序），直观透出原生阅读进度与划线体量；
- **即打即搜**：支持跨全书库实时匹配书名、作者与数千条划线原句，点击任意一本书即可顺畅滑出专属划线抽屉。

![三合一即时藏书检索与全量书架](assets/04-quick-search-modal.png)

#### 3. 单书工作室与对话联动
打开任意一本书的抽屉，书籍全部划线按阅读时间清晰陈列。每条划线支持 **「✨ 联动 DSH 探讨」**，自动向 DeepSeek 填入结构化研读提示词（剥离表面修辞的第一性原理、正反两面与更高维度的辩证审视、直击日常决策的实在自检问题）。

抽屉顶部更提供专注交付的核心出口：
- **💡 选题与现实思考**：自动聚合你在该书中具有共鸣的划线片段，结合当下真实的社会热点、职场或生活痛点，提炼 2-3 个核心议题，并对最关键的概念进行正反逻辑推演与反常识审视，先立住核心骨架。

![单书工作室与对话联动](assets/02-book-highlights-drawer.png)

#### 4. 一键 Markdown 导出，告别发邮件倒腾
平时用 Apple Books 最大的痛点，莫过于笔记划线的导出与归档。  
ReadingOS 通过直接读取本地底层数据，**无需发送邮件、无需任何格式中转，一键就能将全书所有划线（如《估值原理》全书 300 条划线）完整、干净地导出为 Markdown 底稿或复制到剪贴板**。

内置双模式自由切换：
- **📝 全部划线底稿**：完整汇编全书所有原句、序号、批注与记录时间，一条不漏，原汁原味，彻底告别“发邮件倒腾笔记”的原始操作；
- **📑 结构化复盘报告**：提炼全书核心主旨、精选 TOP 8 核心金句（优先呈现你的个人批注）、现实思考与正反辩证审视，文字信息密度高；
- 配套提供一键复制到剪贴板与 `.md` 文件本地下载，无缝衔接 Obsidian、Notion 或本地文本知识库。

![一键 Markdown 导出，告别发邮件倒腾](assets/03-quick-export-modal.png)

#### 5. 纯本地运行，隐私至上
代码完全开源，且仅在本地 macOS 环境中运行。所有图书数据库读取与分析均在本地内存中完成，**绝不向任何外部服务器上传任何书名、划线或笔记数据**，Git 仓库中也仅保留公开示例模板，个人隐私绝对安全。

### 适用与不适用场景（使用前须知）

ReadingOS 最初源于作者个人的日常阅读习惯与偏好，具有特定的使用场景。为避免安装后出现“界面数据为空”的困惑，安装前请留意：

#### ✅ 适合你的情况：
- **纯 macOS 环境**：直接依赖 macOS 原生「图书（Apple Books）」底层 SQLite 数据库，目前暂不支持 Windows / Linux；
- **使用系统自带「图书」且有划线习惯**：在 Mac、iPhone 或 iPad 上阅读 EPUB/PDF 时，会随手划线高亮（多端通过 iCloud 自动同步至 Mac 本地）；
- **电子书存放位置**：默认扫描系统「下载（`~/Downloads`）」文件夹中的书籍文件（亦支持通过环境变量 `READING_OS_BOOKS_DIR` 自定义存放目录）。

#### ❌ 暂不适用或界面可能为空的情况：
- **主要使用第三方阅读平台**：如微信读书、Kindle、多看、MarginNote、得到等（因各平台数据闭源或云端存储，本插件无法越权读取）；
- **通读但不做划线**：若在「图书」中只读书、从未留下任何划线标记，看板的热力图、划线流与抽屉将没有素材可供呈现；
- **书籍存放于外接移动硬盘或特殊路径**：未设置自定义环境变量时，将无法统计下载库概况。

### 后续演进思考（v3.0 展望）

在当下的 v2.0 版本中，我们跑通了从「划线提取」到「辩证探讨」与「一键全量/复盘 Markdown 导出」的完整闭环。

而在真实的深度阅读中，不少读者除了划线之外，更习惯在划线内容旁随手写下自己的**即时思考与批注笔记（Apple Books Note）**。这些写在句子旁边的个人思考，往往比原文更加鲜活，是个人认知迭代的真实见证。

**v3.0 版本的核心演进方向将聚焦于此**：
- **划线与思考笔记双轨共振**：抽屉与看板将深度透出用户针对划线写下的个人思考，并予以醒目标识；
- **以“个人思考”为锚点的 AI 碰撞**：引导 DeepSeek 围绕“你当时的批注与现实困惑”而非仅仅针对“作者原文”展开更具针对性的三维探讨；
- **思考手记卡片化**：将带个人思考的划线升维为知识卡片，支持跨书网状检索与心智资产专题沉淀。

### 环境要求

- **操作系统**：macOS（因为依赖系统原生「图书」底层数据库，暂不支持 Windows / Linux）
- **阅读软件**：macOS 自带「图书（Apple Books）」App（在阅读 EPUB、PDF 电子书时有划线高亮习惯）
- **宿主环境**：[DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) 桌面端

### 安装方法

本插件完全遵从 DeepSeek Harness 官方插件生态规范。

#### 方式一：在 DeepSeek Harness 中在线安装（推荐）
1. 打开 DeepSeek Harness 桌面端；
2. 依次点击左侧栏 **「🧩 插件」 ➔ 「添加插件」**；
3. 在地址输入框中填入本仓库链接：
   ```text
   https://github.com/maikaojai/dsh-plugin-reading-os
   ```
4. 点击 **“安装”**，左侧栏即可出现 **`📖 ReadingOS 读书`** 图标。

#### 方式二：本地软链接开发安装
如果你希望参与开发或本地微调：
1. 克隆本仓库到本地目录：
   ```bash
   git clone https://github.com/maikaojai/dsh-plugin-reading-os.git
   ```
2. 在 DeepSeek Harness 的「添加插件」弹窗中，直接输入本地仓库的绝对路径并确认安装；
3. 本地修改代码后，在 DSH 窗口中按 **`Command + R`** 即可实时看到更新。

### 智能体协作工具 (Agent Tools)

安装后，DeepSeek 在日常对话中也可按需自主调用以下只读工具协助你进行知识回顾：

- `reading_search_highlights`：按关键词检索全书库划线；
- `reading_get_book_highlights`：查询指定书籍的全部划线与笔记；
- `reading_get_concept_network`：探索跨书的主题脉络与关联语段；
- `reading_get_overview`：查看阅读资产总量与分类概况。
